# AeroNest — Drone Photography Website

A responsive, Bootstrap 5 + HTML/CSS/JavaScript homepage concept for a drone photography and aerial videography service.

## Project structure

```text
AeroNest/
├── index.html
├── README.md
└── assets/
    ├── css/
    │   └── style.css
    └── js/
        └── main.js
```

## Run locally
1. Extract `AeroNest.zip`.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Internet access is required for Bootstrap, Bootstrap Icons, Google Fonts, and the Unsplash photographs.

## Included sections
1. Hero and navigation
2. About AeroNest and stats
3. Services (four service cards)
4. Aerial gallery
5. Three-step process
6. Client testimonials
7. Booking call-to-action
8. Contact / booking enquiry form
9. Footer

## Interactions
- Theme toggle (light/dark preference is saved in localStorage)
- LTR / RTL direction switch
- Responsive Bootstrap navigation
- Demo modal (visual placeholder)
- Booking form validation and demo confirmation
- Newsletter front-end confirmation
- Smooth anchor navigation and compact navbar on scroll
